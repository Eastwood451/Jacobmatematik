# Luigi's pizza couriers

Nine transparent WebP sprites cropped from an AI-generated atlas, for the Jacob-only ten-friends pilot. Each numeral carries its own number of slices on a tray. The pizza icon on the cap is decoration.

Art brief: cute anthropomorphic numerals 1–9 with friendly faces, delivery caps, gloves and sneakers, warm polished 3D cartoon style, indigo/orange palette. One transparent 3×3 atlas in reading order. Each courier holds a tray with exactly its numeral count of separate, visible triangular pizza slices. No scene background or extra labels.

Generated using the built-in image generation tool. The ten-wedge pizza in the exercise is deterministic SVG so its count is exact.
